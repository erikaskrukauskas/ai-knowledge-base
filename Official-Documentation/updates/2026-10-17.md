## Worth knowing

- **Claude Code 2.1.295 — hooks** (2026-10-08) — `onFailure: "block"` makes a command or HTTP hook that cannot start, times out, or exits unexpectedly stop the action. [Changelog](https://code.claude.com/docs/en/changelog#2-1-295)
