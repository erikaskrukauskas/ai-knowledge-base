# Books and references

This folder is a catalog of AI engineering references and your notes about them. It is not a library of book files.

## What to store

- Title, author, edition, and year.
- The question the source helps answer.
- Original notes in your own words.
- A short quotation only when you need the exact wording, with a citation.

## What to leave out

- PDFs and ebook files. `.gitignore` ignores `*.pdf` as a backstop.
- Verbatim chapters or reconstructed passages.
- Scanned pages and bulk exports from a reading tool.

Domain textbooks belong in the domain repo's own source list, under the same note-taking rule.

## Catalog

Add a row when you start taking notes. Create `Books/notes/<slug>.md` for the notes and link it here.

## Using a book in a session

Search your notes. Then check current official documentation before you apply a product-specific claim. A book can explain a durable method and still be wrong about a current UI, API, or default.
